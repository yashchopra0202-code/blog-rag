Projects are a single place to manage, create, and collaborate on tasks with shared files and memory.

Today we’re rolling out

, an evolution of Spaces. Projects are hubs for long-running, ongoing work in Computer. A single place to manage, create, and collaborate on tasks with a shared file system and persistent memory.

Projects are built for how people really work. Each Project has a shared, persistent file system where humans and agents collaborate on the same files, and a

that learns from your work so the next task starts with full context from the last.

Because every task works from the same context, Projects are ideal for running many tasks and workstreams at once, often as a team. When collaborating on a shared Project, every team member works from the same files, context, and skills while personal memory and connectors stay scoped to each person's account.

Projects uses a persistent, hierarchical file system. Upload documents, import folders, or pull files from connected sources, and every task in the Project can build on them.

Computer works in the file system the way a teammate would. It can open files, read their latest versions, make edits, and save changes back to the same files. Computer edits the same file rather than starting over every task.

In a shared Project, everyone works from the same source of truth. A teammate's session can pick up the model your session produced yesterday. Scheduled tasks can maintain a status document no one has to remember to update.

Any user can add files to a Project. Mac and Windows users on the desktop app can also connect local files from their desktop, keeping Project context tied to the docs, spreadsheets, and notes on their machine. These local files are only visible to the user who uploaded them and not shared with other users in the Project.

Users can also connect Projects to over 400 tools and apps their team needs, including Google Drive, Notion, Linear, Snowflake, and Github.

Every Project can connect to

, Computer’s self-improving memory system.

Between tasks, Brain studies the Project's shared sessions and files and maintains a living memory of the work that was done. Brain applies what it’s learned to each new task. As a result, every subsequent task starts from accumulated understanding and improves. Users never have to reassemble context from scratch.

Brain also helps keep a Project’s files organized and tasks on track. It can run automatically on a schedule or on demand, reviewing everything it has learned and updating the Project summary.

Skills give Computer reusable instructions for how to work inside a project. Upload a Skill to give Computer preferred steps, structure, and formats.

Teams can easily share and collaborate on a Project with others. When team members are invited into a Project, everyone works from the same sources, artifacts, automations, and history. Projects organize connected sources without pooling every teammate’s private data into one shared source.
